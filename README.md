# Инструкция по запуску Telegram-бота локально

## Требования к системе

Перед началом убедитесь, что у вас есть всё необходимое для работы бота:

- **Python**: версия 3.8 или выше. Вы можете проверить версию Python командой:

  ```bash
  python --version
  ```

  Если Python не установлен, скачайте его с официального сайта.

---

## Шаг 1: Подготовка рабочей среды

### 1.1. Создание рабочей директории

1. Создайте папку для вашего проекта, например `hr_telegram_bot`.

   ```bash
   mkdir hr_telegram_bot
   cd hr_telegram_bot
   ```

2. Эта папка будет содержать все файлы бота.

### 1.2. Установка Python (если не установлен)

- Если Python отсутствует или версия ниже 3.8:

  1. Скачайте установщик с python.org.

  2. Установите Python, обязательно отметив галочку «Add Python to PATH» (для Windows).

  3. Проверьте установку:

     ```bash
     python --version
     ```

---

## Шаг 2: Установка зависимостей

Для работы бота нужны Python-библиотеки. Установите их с помощью менеджера пакетов `pip`.

### 2.1. Обновление pip

Убедитесь, что у вас последняя версия `pip`:

```bash
pip install --upgrade pip
```

### 2.2. Установка библиотек

Выполните команду в терминале:

```bash
pip install aiogram aiohttp python-decouple
```

- `aiogram`: основная библиотека для создания Telegram-ботов.
- `aiohttp`: используется для асинхронных запросов к API hh.ru.
- `python-decouple`: помогает безопасно работать с конфигурационными данными через файл `.env`.

## Шаг 3: Получение токена бота

Для работы бота вам нужен уникальный токен от Telegram.

1. Откройте Telegram и найдите бота `@BotFather`.
2. Напишите `/start`, чтобы начать работу с `@BotFather`.
3. Отправьте команду `/newbot` для создания нового бота.
4. Следуйте инструкциям:
   - Укажите **имя бота** (например, «HRBot»).
   - Укажите **username** бота (должен заканчиваться на «Bot», например, `@HRHelperBot`).
5. После создания `@BotFather` выдаст вам токен, например: `1234567890:ABCDEF1234567890abcdef1234567890`.
6. Скопируйте токен и сохраните его в безопасном месте — он понадобится позже.

---

## Шаг 4: Настройка конфигурации

Конфиденциальные данные (токен бота и ID работодателя) будут храниться в файле `.env`.

### 4.1. Создание файла `.env`

1. В корневой директории проекта создайте файл с именем `.env`:

   - На Windows: используйте текстовый редактор или команду `echo. > .env`.
   - На macOS/Linux: `touch .env`.

2. Откройте файл `.env` в текстовом редакторе и добавьте:

   ```env
   TELEGRAM_BOT_TOKEN=your_bot_token_from_botfather
   EMPLOYER_ID=your_hh_ru_employer_id
   ```

   - Замените `your_bot_token_from_botfather` на токен, полученный от `@BotFather`.
   - Замените `your_hh_ru_employer_id` на ID работодателя с hh.ru (например, `1234567`). Чтобы узнать ID:
     - Зайдите на hh.ru, найдите страницу вашей компании.
     - В URL будет числовой идентификатор, например, `https://hh.ru/employer/1234567`.

3. Сохраните файл `.env`.

## Шаг 5: Подготовка кода бота

### 5.1. Настройка HR_IDS

1. В коде найдите строку:

   ```python
   HR_IDS = [123456789]  # Замените на реальные ID HR-пользователей
   ```

2. Замените `123456789` на реальные Telegram ID пользователей с правами HR.

   - Чтобы узнать Telegram ID:
     - Напишите боту `@userinfobot`.
     - Отправьте `/start`, и он вернёт ваш ID.

3. Сохраните файл.

---

## Шаг 6: Запуск бота

1. Убедитесь, что вы находитесь в директории с файлом `run.py`:

2. Запустите бота:

   ```bash
   python run.py
   ```

3. Если всё настроено правильно, в терминале появится сообщение вроде:

   ```
   INFO:aiogram:Bot started
   ```
